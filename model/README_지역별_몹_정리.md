# MysticMobs 몹 작업 파일 안내

이 폴더는 `공백 RPG 프로젝트 기획서 (초안)`을 기준으로 제작한 몹의 모델, MythicMobs 설정, 스킬 원본을 지역별로 보관한다.

## 기본 구조

```text
model/
├─ 에르덴/
│  └─ 몹 또는 공용 계열/
├─ 바르칸/
│  └─ 몹 이름/
├─ 실바르/
└─ 지역 미분류/
   └─ 몹 또는 테스트 자료/
```

각 몹 폴더는 가능한 경우 다음 세 종류의 파일을 함께 보관한다.

- `*.bbmodel`: 모델 원본
- `*_몹.yml`: MythicMobs Mob 설정
- `*_스킬.yml`: MythicMobs Skill 설정

## 파일명 규칙

- 지역과 몹 폴더명은 기획서상의 한국어 명칭을 사용한다.
- Mob과 Skill YAML은 내용을 알아볼 수 있는 한국어 파일명을 사용한다.
- `.bbmodel` 파일명은 YAML이 호출하는 모델 ID와 동일하게 유지한다.
  - 예: `mid=orc_king` → `orc_king.bbmodel`
  - 예: `mid=orc_archer` → `orc_archer.bbmodel`
- `.bbmodel` 이름을 임의로 번역하거나 변경하면 Mob/Skill의 모델 호출이 끊길 수 있다.

## 현재 지역별 자료

### 에르덴

- 슬라임
- 슬라임 여제
- 초원 늑대
- 강화 늑대
- 늑대 공용 공격 모델
- 야생 곰
- 고블린 계열
- 고블린 대장

`고블린 계열`은 여러 고블린 정의와 보조 모델을 하나의 Mob/Skill YAML에서 함께 사용하므로 단일 묶음으로 보관한다. `늑대 공용`에는 초원 늑대와 강화 늑대가 함께 사용하는 물기·할퀴기 모델을 보관한다.

### 바르칸

- 바르칸 용병
- 바르칸 정예 용병
- 말단 오크
- 오크 전사
- 오크 궁수
- 오크 킹
- 전쟁 망자

### 실바르

현재 대응 구현 파일이 확인되지 않아 구현 예정 몹을 별도 README에 기록한다.

### 지역 미분류

현재 기획서 지역과 연결하지 않은 자료를 보관한다.

- 태엽골렘
- 폭풍의 브리즈
- 테스트 몹

## 현재 서버 로딩 대상

버킷 내부에는 오크 킹 전투와 소환 패턴에 필요한 오크 계열만 배치한다. 지역 폴더 없이 각 플러그인의 로딩 폴더 최상위에 둔다.

### MythicMobs Mob

- `오크 킹_몹.yml`
- `말단 오크_몹.yml`
- `오크 전사_몹.yml`
- `오크 궁수_몹.yml`

### MythicMobs Skill

- `오크 킹_스킬.yml`
- `말단 오크_스킬.yml`
- `오크 전사_스킬.yml`
- `오크 궁수_스킬.yml`

### ModelEngine Blueprint

- `orc_king.bbmodel`
- `orc_minion.bbmodel`
- `orc_warrior.bbmodel`
- `orc_archer.bbmodel`

현재 오크 킹의 소환 패턴은 MythicMob ID `Orc_Archer`를 직접 호출한다. 따라서 최소 필수 소환 대상은 오크 궁수이며, 말단 오크와 오크 전사도 오크 계열 패턴 확장을 위해 함께 로드한다.

## 작업 및 배포 원칙

1. 원본 수정은 먼저 `model/지역/몹 이름/`에서 관리한다.
2. 서버 테스트가 필요한 Mob·Skill·BBModel만 각 플러그인 로딩 폴더로 복사한다.
3. 복사 후 YAML의 MythicMob ID, Skill 이름, 모델 `mid`와 `.bbmodel` 파일명을 대조한다.
4. 같은 MythicMob ID나 모델 ID가 중복 로드되지 않도록 동일 파일을 여러 로딩 경로에 두지 않는다.
5. 오크 킹 소환 패턴을 변경할 경우 `summon{type=...}`에 지정한 Mob 파일도 반드시 서버에 함께 배치한다.

## 기존 이름 대응

- 기존 `황야 늑대` → 기획서 분류 `초원 늑대`
- 기존 `검정 늑대` → 기획서 분류 `강화 늑대`
- 기존 `고블린 투석병` → 기획서 역할 분류 `고블린 정찰병`
- 기존 `고블린 킹` → 기획서 명칭 `고블린 대장`
- 기존 `말탄 오크` / 모델 ID `orc_minion` → 기획서 분류 `말단 오크`
