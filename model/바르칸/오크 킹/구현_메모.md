# 오크 킹 v0.6 구현 메모

기준: 설치된 MythicMobs 5.13.0 / ModelEngine 4.1.0. 최신 변경의 서버 내 실전 테스트 전 단계입니다.

## 추가 변경 및 궁수 조사

- `glaive_smash` 시작 거리를 **5블록 초과~10블록 이하**로 제한했습니다. 기존 combo > 10 조건과 강공격 피해 범위 4블록은 유지합니다. 5블록 이내 랜덤 후보에서도 제거했습니다.
- 오크 킹의 `KnockbackResistance`를 0.70으로 설정했습니다. 일반 넉백 70% 저항을 의도한 값이며 강제 이동 스킬에는 별개입니다.
- 후방 피격은 기본 엔티티 시선 기준 뒤쪽 180도에서 공격한 플레이어로 판정합니다. 피격 방향은 즉시 검사하고, 해당 피격의 기본 위협도 증가가 끝나도록 1틱 뒤 전체 위협도 초기화 → 공격자 위협도 100 덮어쓰기 → 타깃 설정을 실행합니다.
- 기존 runner의 강제 추격 대상 고정 로직은 유지했습니다. 따라서 runner 진행 중에는 후방 피격으로 위협도를 바꾸어도 다음 추격 갱신에서 고정 대상을 다시 바라볼 수 있습니다. runner를 중단시키는 우선순위 변경은 별도 결정 사항입니다.
- 궁수 조사: 소환은 보스 위협도를 복사하고 최고 위협 대상을 선택하는 코드 경로입니다. 등장 중 AI를 끈 뒤 28틱 후 재활성화하지만, 등장 완료 시 타깃을 재지정하거나 무타깃 상태를 복구하는 처리는 없습니다. 공격/추적 타이머는 incombat 조건에 묶여 있어 교전 상태가 풀리면 이 타이머만으로 복구되지 않습니다. 두 번째 소환부터 발생한다는 현상은 아직 재현하지 못해 원인 확정은 아닙니다. 궁수 파일은 이번 조사에서 수정하지 않았습니다.

## 반영한 설정

- 기존 체력 300, 일반 스킬 피해 10, 강공격 15, 이동속도 0.24 유지. 구체적인 능력치는 별도 밸런싱 대상입니다. 방어력을 무시하지 않습니다.
- `count`: 대기 0 / 걷기 -1 / 일반 달리기 -2 / attack1~3 각각 1~3 / 투창 4 / 소환 5 / 강공격 6 / runner 투창 7 / 빠른 추격 8 / 사망 99.
- 공격 시작 시 이동 모션을 제거하고 잠급니다. 지연 타격·소환·잠금 해제는 해당 상태인지 다시 검사합니다.
- 콤보: 플레이어에게 피격 시 +1, 플레이어에게 스킬 피해를 주면 +2. 두 방향이 같은 20틱 증가 잠금을 공유합니다. 증가가 막힌 동안에도 교전 시간은 갱신합니다.
- 200틱 동안 교전이 없으면 콤보 초기화. 소환 등장 완료 시 콤보 -10, 최저 0.
- 콤보 0~10: 근접 attack1:attack2=2:1. 11부터 attack3·강공격, 21부터 소환 허용. 근접 3종의 상대 가중치는 1:1:1입니다. 거리상 닿지 않는 공격은 해당 거리 구간의 후보에서 제외합니다.
- runner: 6블록 이상에서 피격되면 +1:+2=1:2. 증가 잠금 10틱. 증가가 막혀도 마지막 원거리 공격자의 UUID는 갱신합니다.
- **투창은 combo 11 이상과 runner 10 이상을 동시에 만족해야 합니다.** 두 조건을 만족하고 마지막 원거리 공격자가 5블록 밖이면, 현재 패턴 종료 후 그 대상을 고정하여 위협도 전체 초기화 → 해당 대상 200 설정 → 투창 → 1.5배속 추격 순서로 실행합니다. 일반 combo 랜덤 공격 후보에는 투창이 없습니다.
- 추격 중 새 피격으로 추격 대상이 바뀌지 않습니다. 2블록 이내 도착 시 해당 대상 위협도는 30으로 덮어쓰고 runner를 0으로 되돌립니다. 다른 플레이어가 추격 중 쌓은 위협도는 보존합니다.
- 대상 사망·이탈 등으로 유효 대상이 2초 동안 확인되지 않으면 추격 잠금을 해제합니다. 정상 추격에는 임의의 시간 제한을 두지 않았습니다.
- 기존 `Orc_Archer`를 좌우 2블록에 한 마리씩 소환합니다. 소환된 개체의 `ok_damage_multiplier`만 0.7로 설정하고, 기존 화살 피해식에 곱합니다. 기본 궁수는 1.0입니다. 기본값 9 기준 소환 궁수는 방어 적용 전 6.3입니다.
- 소환 쿨다운은 30초입니다. 궁수는 등장 중 이동·공격을 잠그고 초록 먼지/수풀 소리로 등장합니다. bbmodel 및 모델 ID는 변경하지 않았습니다.

## 타이밍

20 TPS 기준 정수 틱으로 반올림했습니다. 서버 렉이 있으면 실제 시간은 길어질 수 있습니다.

| 이벤트 | 요청 | 적용 |
| --- | --- | --- |
| attack1 피해 | 0.84초 | 17틱 / 0.85초 |
| attack2 피해 | 0.73초 | 15틱 / 0.75초 |
| attack3 피해 | 0.75초 | 15틱 / 0.75초 |
| 투창 발사 | 0.72초 | 14틱 / 0.70초 |
| 궁수 등장 시작 | 1.25초 | 25틱 / 1.25초 |
| 궁수 등장 완료 | 2.63초 | 53틱 / 2.65초 |
| 강공격 추격 시작 | 1.12초 | 22틱 / 1.10초 |
| 강공격 추격 정지 | 1.63초 | 33틱 / 1.65초 |
| 강공격 피해 | 2초 | 40틱 / 2초 |

attack1은 반경 4 / 180도, attack2는 반경 3 / 210도에 중심을 왼쪽 15도로 회전합니다. attack3은 요청에서 허용한 대안인 반경 5 / 60도 전방 부채꼴입니다. 역부채꼴은 구현하지 않았습니다.

각 근접 공격은 피해 2틱 전에 공격 종류에 맞는 예고음을 재생합니다. 대표 타격 틱에는 피해 판정과 동시에 피격 대상 위치의 소리·파티클을 실행하고, 공격 방향에도 휘두르기/찌르기 효과를 표시합니다. 강공격은 지면 충돌음과 넓은 먼지를 추가했습니다. 모든 위치에서 무기와 몸이 물리적으로 접촉하도록 다단 판정을 만들기보다, 한 번의 대표 타격 프레임을 소리와 반응으로 강조하는 착시 설계입니다. 피해량·범위·실제 피해 틱은 변경하지 않았습니다.

## 남은 제약과 결정 사항

1. **투창 방식 확정·설정 반영:** 사용자 승인에 따라 발사 후 10틱(약 0.5초) 동안 유도한 뒤 중력 낙하합니다. 중력 지원 `projectile` 하나의 방향을 `setProjectileDirection`으로 보정하다가 보정을 멈추고 `modifyProjectile`로 중력 0.012를 적용합니다. 목표는 발사 시 UUID로 고정하며 몸통 높이를 조준합니다. runner 투창은 플레이어를 관통하되, 첫 관통 시에는 즉시 유도를 끊어 되돌아오지 않게 합니다. 같은 투사체를 유지하므로 관통 면역 시간도 유지됩니다. 블록에 닿으면 소멸하며 최대 수명/거리 안전장치도 유지합니다. 유도 시간·낙하 곡선은 인게임에서 조정할 초기값입니다.
2. **OP 판정 제약:** 메시지는 `minecraft.command.op` 권한으로 필터링합니다. 일반적인 기본 권한 설정에서는 OP에게만 보이지만, 이 권한을 비OP에게 별도 부여하면 그 사람도 볼 수 있습니다. 이는 서버의 `isOp()` 직접 검사와 다릅니다. 엄격한 OP 신분 판정은 아직 충족하지 못했습니다.
3. **궁수 전용 등장 애니메이션 없음:** 기존 모델에 해당 애니메이션이 없어 수풀 느낌의 임시 효과로 처리했습니다. 모델 자체의 새 모션 제작은 별도 작업입니다.
4. **charge_start / charge_end 미사용:** 어떤 패턴에 연결할지 지정되지 않아 기존 공격 타이밍을 바꾸지 않았습니다.
5. 창은 파티클 선과 창끝 표현입니다. 유도 중 회전에 대한 시각 확인이 필요합니다.

## 검증

완료: YAML 문법/중복 키, 스킬·랜덤 선택·콜백·소환 몹 참조 검사. 실제 bbmodel의 애니메이션 이름/길이 확인.

아직 미실행: 서버 리로드, 실제 소환, 피해 이벤트·위협도 전환·애니메이션과 판정 일치 확인. 정적 검사 통과가 플러그인 실행 검증을 뜻하지 않습니다.

게임 내 확인 항목:

- 콤보 10/11, 20/21 경계 및 runner 9/10 경계.
- 여러 플레이어의 동시·다단 공격에서 콤보 1초 1회, runner 0.5초 1회 제한.
- 콤보 잠금 중 교전해도 비전투 초기화 시간이 연장되는지 확인.
- 근접 공격 범위 밖/옆/뒤에서 피격 여부, 특히 attack2의 왼쪽 추가 30도.
- 투창 모션 중 이동하지 않고, 종료 후 빠른 추격으로 전환되는지 확인.
- 투창 발사 후 약 0.5초까지만 방향을 보정하고 이후 이동하는 플레이어를 따라 꺾이지 않으며 떨어지는지 확인. 일반/runner 모두 벽에서 소멸하는지, runner가 관통한 대상을 다시 타격하지 않는지 확인.
- 추격 중 다른 플레이어가 위협도를 쌓은 뒤 도착 시 커버가 가능한지 확인.
- 일반 궁수와 소환 궁수의 동일 장비 대상 피해 비교, 등장 중 공격 금지.
- 사망 직전에 예약된 타격·소환·이동 재개가 실행되지 않는지 확인.
- OP와 일반 계정에서 디버그 수신 범위 확인. 피해 출력은 이벤트의 피해 값이며, 체력 감소량과 일치하는지도 확인.
