# 오크킹 — 개발 완료

사용자 확정 완료본, 리비전 5. `오크 킹/`은 본체, `오크 궁수/`는 소환 패턴 의존 파일이다.

- 개발 원본: `model/바르칸/오크 킹`, `model/바르칸/오크 궁수`. 이 폴더는 완료 시점의 스냅샷이다. 후속 수정은 원본에서 진행한 뒤 갱신한다.
- 설치: bbmodel은 ModelEngine blueprints, `*_몹.yml`은 MythicMobs mobs, `*_스킬.yml`은 skills에 배치한다. 같은 ID의 기존 파일을 교체하며 중복 설치하지 않는다.
- 최초 설치 시 ModelEngine 모델 빌드·리소스팩 적용 및 MythicMobs 리로드가 필요하다.
- 알려진 버그: `glaive_start → glaive` 전환 끊김. 가까운 다른 오크 모델이 있을 때 개선되는 경향, 원인은 미확정. 추가 조사는 보류했다.
- 정적 모델·YAML/참조 검사는 통과. 최근 타깃 전달 수정의 인게임 결과와 버그 해결은 미확인이다.
- 상세 명세: [오크킹](../../../tasks/오크킹.md).
