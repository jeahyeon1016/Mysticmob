- 리비전: 5
- 담당: main(통합 완료). /root/glaive_first_use_check 및 /root/king_model 완료, 소유권 해제.

## 목표·확정 동작

- 기존 glaive_smash의 공중 창 회전과 착지·전방 베기를 분리한다. 회전 중 타깃을 추격하고 도달한 뒤에만 smash를 실행한다. attack1/2로 대체하지 않는다.
- 기존 준비·도약은 한 번만 재생한다. 필요하면 glaive_start를 두고, 공중 회전 glaive는 LOOP, 착지·베기 smash는 ONCE로 재생한다.
- 도달 기준은 기본 3블록(기존 attack1/2 모두 가능한 거리), 추격 속도는 기존 2배. 기존 시작 조건 combo > 10, 거리 >5~10을 유지한다.
- 회전 중 피해 없음. smash 타격 시 기존 전방 4블록·180도·피해 15 단일 판정, 타격 2틱 전 예고음을 유지한다.
- 타깃 상실·사망·도달 불가로 잠금이 영구 유지되지 않아야 한다. 안전 추격 제한 기본 200틱. 취소는 피해 없이 정리한다.
- 후속 요청: glaive_start → glaive 끊김이 첫 시전에서만 나타나는지 조사. 재현 없이 첫 시전 캐시 문제로 단정하지 않는다.
- 투창은 기본 유도 상한을 10틱에서 5틱(0.25초)으로 줄이고 이후 플레이어 위치를 추종하지 않는다. 기존 중력·피해·관통·속도는 유지하며, 관통 시에도 즉시 유도 종료한다.

## 소유권·공용 계약

- Model worker 수정: model/바르칸/오크 킹/orc_king.bbmodel만. 원본 glaive_smash와 나머지 모델·텍스처·애니메이션은 보존하고 분리 모션을 추가한다.
- Main 수정: model/바르칸/오크 킹/오크 킹_스킬.yml, 필요한 경우 오크 킹_몹.yml; 이 명세와 작업 전용 검증.
- Model worker는 준비 모션 길이, 반복 길이·경계 자세, smash 타격·종료 시각을 main에 전달한다. 그 결과 전에는 main이 모션 지연을 확정하지 않는다.
- 서로의 파일, 궁수 원본, 서버 실행 사본, Git 상태는 worker가 수정하지 않는다. 후속 사용자 요청으로 main의 서버 반영·재빌드 진행이 범위에 추가됨. 푸시는 범위 밖.
- 참고: https://wiki.mythiccraft.io/modelengine/Skills/Mechanics/State (LOOP/ONCE/제거). 설치 파일명 ModelEngine 4.1.0 / MythicMobs 5.13.0 확인.
