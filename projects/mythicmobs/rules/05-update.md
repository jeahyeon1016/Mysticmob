# 최신화

최신 기준은 `D:\ai agent\projects\mythicmobs` 로컬 작업본이다. 사용자가 최신화를 요청하면 실행본을 로컬 원본에 반영하고, 맵·런타임 부산물을 제외한 변경분을 통합 저장소 `https://github.com/jeahyeon1016/ai-agent`의 `master` 브랜치에 커밋·push한다. PaperResources 리소스팩 ZIP도 동일 저장소의 `projects/mythicmobs/bukkit/plugins/ModelEngine/` 경로에 포함한다. 규칙·기획·상태 문서도 통합 저장소에 포함한다.
