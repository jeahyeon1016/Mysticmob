# 검증된 오류·해결

다른 몹에서도 재발할 수 있고 인게임에서 확인된 내용만 짧게 기록한다.

```text
증상:
원인:
해결:
적용 조건:
```

## 엔트 미니언 추격 방향 오류

```text
증상: 플레이어를 타겟으로 잡았지만 몹이 플레이어 반대 방향으로 이동함.
원인: AITargetSelectors를 clear로 둔 상태에서 수동 setTarget과 movetowardstarget을 조합함.
해결: AITargetSelectors에 players를 사용하고 meleeattack과 movetowardstarget을 함께 구성함.
적용 조건: 일반적인 플레이어 추격 AI가 필요한 근접 몹.
```

## 엔트 미니언 공격 범위 미세 판정 오류

```text
증상: 공격 범위 안에 정지한 플레이어가 있어도 간헐적으로 맞지 않음.
원인: 좌표 기반 전방 판정값이 실제 체감 거리보다 조금 크게 계산됨.
해결: 전방 판정 범위를 0~2에서 0~2.2로 조정함.
적용 조건: 전방·좌우 좌표 조건으로 근접 공격 범위를 판정하는 몹.
```

## 공격 사운드 타이밍

```text
증상: 공격 사운드가 애니메이션 시작에 재생되어 실제 피해 시점과 어긋남.
원인: 공격 상태를 시작하는 줄에 sound를 배치함.
해결: damage mechanic 직후에 공격 사운드를 배치함.
적용 조건: 애니메이션 타격 시점이 있는 공격.
```
