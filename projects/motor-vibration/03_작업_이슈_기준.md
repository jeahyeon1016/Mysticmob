# 3. 작업·이슈 작성 기준

## 이슈에 반드시 기록할 항목

- 담당 파트·담당자·우선순위
- 관련 주차·기능 ID
- 현재 상태와 변경 후 목표
- 작업 범위와 제외 범위
- API·데이터 필드·null 처리
- 선행 작업·관련 이슈·협의 담당
- 완료 기준과 검증 방법
- 미구현·미검증 항목
- 참고 기획서·명세·PR

## 완료 기준

- [ ] 요구사항에 맞게 구현
- [ ] 정상·오류·경계 조건 테스트 통과
- [ ] 기존 기능 호환성 확인
- [ ] 관련 문서 갱신
- [ ] 미구현·미검증 항목 명시
- [ ] PR 리뷰 및 머지 완료
