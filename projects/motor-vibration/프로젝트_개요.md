## 목표

- 모터에서 진동·음향 데이터를 안정적으로 수집
- ESP32가 서버로 측정 결과를 전송
- Backend가 데이터를 저장·관리
- AI가 정상/이상 상태를 분석
- 최종적으로 현장 모터 상태를 모니터링

## 구성

| 영역 | 역할 |
|---|---|
| Hardware | 진동 센서, 마이크, ESP32, 외함 및 배선 |
| IoT | 센서 수집, 로컬 저장, HTTPS 전송, 장치 상태 보고 |
| Backend | API, 인증, telemetry 수신·저장 |
| AI1/AI2 | 특징 추출, 이상 탐지, 결과 제공 |
| Frontend | 상태·분석 결과 화면 |

## 현재 담당 범위

- 담당 파트: `IoT`
- 담당 업무: 하드웨어 및 ESP32 펌웨어
- 저장소: `D:\ai agent`
- 최신 원격 저장소: https://github.com/jeahyeon1016/ai-agent
- 현재 브랜치: `feat/esp32-telemetry-integration`
- 4주차 MVP: 완료

## 현재 상태

- 운영 HTTPS endpoint 및 장치 ID 적용 완료
- CA 인증서 검증 활성화
- telemetry와 device health 인증 경로 적용
- LittleFS 오프라인 데이터 처리 개선
- 서버 ACK 중첩 메타데이터 처리 및 회귀 테스트 완료
- 실서버 telemetry 전송 확인: HTTP 201
- Native firmware 테스트: 기존 기준 56/56 통과
- 기존 펌웨어 PR: https://github.com/ckdudwns/MotorDiagnosis/pull/34
