# 모터 진동 프로젝트 규칙

1. 작업 시작 시 상위 `start.md`와 이 문서를 읽는다.
2. 이 프로젝트의 최신 기준은 현재 로컬 폴더다.
3. 변경 전 관련 기획서·API 명세·협업 표준을 확인한다.
4. 하드웨어·ESP32 펌웨어 범위와 Backend·Frontend·AI 협업 범위를 구분한다.
5. 실제 토큰, 비밀번호, `secrets.h`는 commit하지 않는다.
6. 정상·오류·경계 조건을 검증하고 결과를 `STATE.md`에 기록한다.
7. 검증 완료 후에만 통합 `ai-agent` 저장소에 commit/push한다.
