## 원인

- TLS `HTTP -1`은 간헐적인 HTTPS 연결 실패로 확인됨.
- LittleFS `lfs_file_close` assertion은 파일 핸들 관리 문제로 조사 필요.
- Health journal full은 상태 기록 포화이며 sensing·telemetry와 분리됨.

## 수정

- 원시 전송 상세 로그를 최초 ACK 성공 1회만 출력.
- RAW-DEBUG를 10개 윈도우당 1회로 제한.
- ADXL345 FIFO drain 후 불필요한 지연 제거.

## 검증

- ESP32-S3 N8 빌드·COM7 업로드 성공.
- PSRAM 및 ADXL345 `0xE5` 초기화 성공.
- 원시 512샘플 `quality=valid` 확인.
- 원시 API HTTP 202 및 배치 ACK 확인.
- 일반 telemetry HTTP 201, Health HTTP 200 확인.
