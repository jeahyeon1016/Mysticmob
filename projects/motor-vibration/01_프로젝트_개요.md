# 1. 프로젝트 개요

## 한 줄 설명

모터의 진동·소리를 ESP32로 측정하고, 서버와 AI로 이상 상태를 진단한다.

## 전체 구성

- Hardware: 진동 센서, 마이크, ESP32, 외함·배선
- IoT: 센서 수집, 로컬 저장, HTTPS 전송, 장치 상태 보고
- Backend: API, 인증, telemetry 수신·저장
- AI1/AI2: 특징 추출, 이상 탐지, 분석 결과
- Frontend: 장치 상태와 진단 결과 표시

## 프로젝트 목표

1. 모터 데이터를 안정적으로 측정한다.
2. ESP32가 서버로 데이터를 전송한다.
3. 서버와 AI가 데이터를 관리·분석한다.
4. 현장 모터 상태를 모니터링한다.

## 담당 범위

- 담당 파트: `IoT`
- 담당 업무: 하드웨어 및 ESP32 펌웨어
- Backend·Frontend·AI 기능은 협업 대상이며 직접 담당 범위가 아니다.
